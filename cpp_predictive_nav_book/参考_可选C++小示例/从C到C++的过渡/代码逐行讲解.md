# 第 1 章：代码逐行讲解

请先完成 [跟着我一步一步操作.md](跟着我一步一步操作.md) 的第 1～3 步。你不用记住所有内容；每次只读一小段，回头看对应代码即可。

## 先看全貌

程序从 `main()`（第 82～100 行）开始运行。`main()` 准备一组数字，交给 `RangeFilter` 过滤，然后调用 `print_summary()` 打印结果。

其余代码是在 `main()` 之前提前定义好的“工具”：

```text
第 4～10 行   告诉编译器要使用哪些现成工具
第 12～80 行  给我们的代码套上项目名字
第 15～19 行  定义处理结果长什么样
第 22～61 行  定义过滤器
第 63～78 行  定义打印结果的函数
第 82～100 行 程序真正从这里开始执行
```

## 第 1～10 行：注释与 `#include`

第 1、2 行以 `//` 开头，是**注释**。编译器会完全忽略它们；它们只写给读代码的人看。

第 4～10 行每一行都以 `#include` 开头。它们表示：“我想使用 C++ 标准库中已经写好的功能，请把对应说明拿来。”例如：

- 第 7 行 `<iostream>` 让我们能用 `std::cout` 打印文字；
- 第 10 行 `<vector>` 让我们能使用 `std::vector`；
- 第 4 行 `<cmath>` 让我们能检查一个数是否有限。

你不需要手写这些库，也不需要知道它们内部怎么实现。可以把它理解成 C 中 `#include <stdio.h>` 的升级版。

## 第 12 行与第 80 行：`namespace`

第 12 行：

```cpp
namespace predictive_nav::tutorial {
```

意思是“从现在开始，到第 80 行结束，里面定义的名字都属于 `predictive_nav::tutorial` 这个名字空间”。

例如第 22 行定义的类，完整名字其实是 `predictive_nav::tutorial::RangeFilter`。第 94 行创建它时正是这样写的。你可以暂时把 `namespace` 理解成给名字加上一个很长的姓氏，以防不同人都写了一个叫 `RangeFilter` 的类而打架。

第 80 行的 `}` 只是结束这个范围。每一个 `{` 最终都要有匹配的 `}`；这和 C 相同。

## 第 15～19 行：`struct ScanSummary`

```cpp
struct ScanSummary {
  std::size_t valid_count{0};
  double nearest_range{std::numeric_limits<double>::infinity()};
  std::vector<double> valid_ranges;
};
```

这是在定义一种新数据类型，名字叫 `ScanSummary`，中文可理解为“扫描结果摘要”。它还没有创建任何具体结果，只是在说“以后一个结果应该包含哪些东西”。

- 第 16 行保存有效数字的数量。`{0}` 表示默认从 0 开始；
- 第 17 行保存最近距离。先设成“无穷大”，这样第一项真实有效距离一定会比它小；
- 第 18 行保存所有有效距离；`std::vector<double>` 就是一串会自动管理长度的 `double` 数字；
- 第 19 行的分号表示这个 `struct` 定义结束。C 的 `struct` 定义后也要分号。

## 第 22～30 行：类和构造函数

第 22 行的 `class RangeFilter` 代表“过滤器”这种对象。它把两个阈值和处理方法放在同一个盒子里。

第 23 行的 `public:` 表示后面内容可以从类外使用。第 25 行的 `RangeFilter(...)` 与类同名，因此它是**构造函数**：第 94 行创建过滤器对象时，它会自动执行。

第 26 行：

```cpp
: min_range_(min_range), max_range_(max_range) {
```

冒号后的部分叫“成员初始化列表”。现在把它按中文读成：把传进来的 `min_range` 复制到对象内部的 `min_range_`，把 `max_range` 复制到内部的 `max_range_`。末尾下划线是为了表明“这是对象内部保存的成员”。

第 27～29 行检查阈值是否合理。`&&` 是“并且”，`!` 是“不是”。如果最小值不是非负数，或最小值不小于最大值，就在第 28 行报告错误并拒绝创建这个不合理的过滤器。

## 第 34～56 行：真正过滤数据的函数

第 34 行可以先只按意思读：

```cpp
ScanSummary filter(一串只读的 double 数字) const
```

它接收 `ranges`，最后返回一个 `ScanSummary`。末尾 `const` 表示它不会修改过滤器的两条规则。

第 35 行创建一个空的结果摘要。它会自动使用刚才的默认值：数量为 0，最近距离是无穷大，列表为空。

第 37 行是遍历：把 `ranges` 中的每一个数，依次叫作 `range`。第 39 行检查它是不是一个正常有限数字；不是就执行第 40 行 `continue`，即“跳过本轮，直接检查下一个数字”。

第 43 行检查数值是否太小或太大。`||` 是“或者”；只要一个条件为真，就在第 44 行跳过。

第 47 行把通过检查的数添加到结果列表；第 48 行把计数加一。第 50～52 行和你在 C 中找最小值的 `if` 写法一样：如果现在的数字更小，就把它记作最近值。

第 55 行 `return summary;` 表示把完整处理结果交还给调用者。第 56 行结束函数。

## 第 58～61 行：`private` 数据

`private:` 后的 `min_range_` 和 `max_range_` 是过滤器对象的内部数据。`main()` 不能直接写 `filter.min_range_ = ...`；只能在创建对象时给它规则。这样可以避免其他代码在运行到一半时随意破坏过滤规则。

## 第 63～78 行：打印函数

`print_summary` 接收一个只读的结果摘要。第 64 行的 `std::cout <<` 是“输出到终端”。`<<` 可以理解为把右侧内容依次送进屏幕。

第 66～69 行处理一种特殊情况：如果没有任何有效距离，打印一句话后 `return`，不再继续打印“最近距离”。这样不会错误地把无穷大显示成真实距离。

第 71、72 行控制小数显示为两位，例如 `0.20`；第 74～76 行再次遍历有效距离列表，逐个打印。

## 第 82～100 行：`main()`，程序入口

C++ 程序总是从 `main()` 开始执行。第 84～92 行创建一串模拟距离。你能直接看到真实值 `0.03`、`0.20` 等，也能看到第 88 行的 `NaN` 和第 90 行的无穷大，它们是在模拟激光可能给出的不可靠读数。

第 94 行创建过滤器：最小距离 `0.10 m`、最大距离 `6.00 m`。第 95 行调用过滤器的 `filter()` 方法，并把结果保存到 `summary`。

第 97 行先打印原始数量。第 98 行调用我们提前写好的打印函数。第 99 行的 `return 0;` 表示“程序正常结束”。

## 读完后只要会这一件事

请指着第 94、95 行说出：第 94 行创建一个带规则的过滤器；第 95 行把一串距离交给它，并得到一个结果。这就足够进入下一次学习。其余词汇会在后面不断重复出现。
