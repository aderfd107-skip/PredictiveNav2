# 第 1 章：跟着我一步一步操作

这不是考试，也不是练习题。你无需自己写任何 C++ 代码。现在的目标只有一个：让你亲眼看到“已有代码可以被编译和运行”，并知道改动一个数字会改变结果。

## 第 0 步：打开终端

在 Ubuntu 桌面按键盘上的 **Ctrl + Alt + T**。会出现一个黑色或深色窗口，里面有一行文字和一个闪烁的光标；这就是终端。

终端不是“只能高手使用”的工具。你现在只把它当作一个接收命令的窗口：复制一行、粘贴、按 Enter。出错也不会把项目弄坏；只要没有输入删除命令，代码文件不会消失。

## 第 1 步：进入项目目录

复制下面这一整行到终端并按 Enter：

```bash
cd /home/aderfd/PredictiveNav2
```

`cd` 是英文 change directory（切换目录）的缩写。这条命令只是告诉终端：“接下来的操作在 PredictiveNav2 项目文件夹内进行。”它不会修改任何文件。

接着复制：

```bash
pwd
```

屏幕应显示：

```text
/home/aderfd/PredictiveNav2
```

`pwd` 的作用只是显示“我现在在哪个文件夹”。如果显示的不是上面这行，再重新执行第 1 步第一条命令。

## 第 2 步：让电脑把 C++ 文件编译成可运行程序

复制下面三行。注意：第一、二行末尾有反斜杠 `\`，它表示命令还没写完；请连续粘贴三行后再按 Enter，或整段一起粘贴。

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic \
  cpp_predictive_nav_book/01_C到C++的过渡/examples/laser_ranges_intro.cpp \
  -o /tmp/laser_ranges_intro
```

现在不用背这些参数。只需知道：

- `g++` 是 C++ 编译器；它把人写的 `.cpp` 文本翻译为电脑可以执行的程序；
- `.cpp` 后面那段路径是我们给它的 C++ 文件；
- `-o /tmp/laser_ranges_intro` 指定编译后的程序临时放在哪里；
- 成功时一般**没有任何输出**，会直接出现新的命令提示符。这是正常现象，不是卡住。

如果屏幕出现很多英文报错，不要慌，也不要随意改代码。把报错从第一行到最后一行复制给我即可。

## 第 3 步：运行程序

复制：

```bash
/tmp/laser_ranges_intro
```

你应该看到类似下面的结果：

```text
原始距离数量: 7
有效距离数量: 3
最近有效距离: 0.20 m
有效距离: 0.20 1.25 3.70
```

现在只理解结果的中文含义：程序拿到 7 个“模拟激光距离”；丢掉无效或太近、太远的值；最后留下 3 个可用距离，其中最近的是 0.20 米。

## 第 4 步：只改一个已经指定的数字

这一步是可选的；如果你还不熟悉编辑文件，可以先跳过，直接阅读逐行讲解。

在文件管理器或编辑器中打开：

```text
/home/aderfd/PredictiveNav2/cpp_predictive_nav_book/01_C到C++的过渡/examples/laser_ranges_intro.cpp
```

找到第 94 行附近这一行：

```cpp
const predictive_nav::tutorial::RangeFilter filter(0.10, 6.00);
```

只把 `0.10` 改成 `0.50`，其他字符一个也不要动。保存文件后，重复第 2 步和第 3 步。

你会发现有效距离从 3 个变成 2 个，`0.20` 不再出现。原因很简单：过滤器现在认为小于 0.50 米的数都不使用。

这已经是一次真实的“改代码 → 编译 → 观察行为”的开发过程。你不需要自己发明代码；先能安全地修改明确的位置就很好。
