# 09：计算候选轨迹与障碍物距离

> 本步目标：遍历 MPPI 候选机器人轨迹与 prediction，得到同一时刻的距离；先记录距离，不写最终风险公式。

## `CriticData` 中的候选轨迹

MPPI 把候选轨迹保存成张量。对二维差速模型，可以先把它理解为：

```text
data.trajectories.x(i, k)    第 i 条候选在第 k 个未来时刻的 x
data.trajectories.y(i, k)    第 i 条候选在第 k 个未来时刻的 y
data.costs(i)                第 i 条候选的总 cost
```

`i` 是候选编号，`k` 是时间编号。`costs(i)` 没有时间维度，因为一条候选在所有未来点的
代价会累加成一个总分。

## 第一版距离是什么

对于机器人候选点 `r=(rx, ry)` 和障碍物预测点 `o=(ox, oy)`：

```text
dx = rx - ox
dy = ry - oy
distance = sqrt(dx² + dy²)
```

只有机器人和障碍物在同一坐标系、同一未来时刻时，这个距离才有意义。第 10 步会解决
两边时间采样间隔不一致时的插值；本步先把循环、数据维度和最小距离日志做正确。

## 需要遍历什么

```text
for 每条候选 i:
  for 每个候选时间点 k:
    for 每个有效障碍物 j:
      读取同一时刻的障碍物预测点
      计算 distance
      更新本周期最小距离
```

不要把“所有障碍物中的最小距离”写入每条候选的同一个变量；每条候选都必须独立计算，
否则 MPPI 无法比较不同动作的风险。

## 如何观察结果

先只节流打印：候选条数、时间步数、有效预测目标数和本周期最小距离。开阔区域最小距离
应较大；让 actor 横穿预期路径时，最小距离应下降。

如果距离突然为 0、NaN 或极大数，先回到第 08 步检查 frame、时间戳、数组长度和 finite，
不要急着调 risk 权重。

## 本步完成标准

- [ ] 能解释 `i` 和 `k` 两个维度；
- [ ] 每条候选独立计算距离；
- [ ] 只比较同一坐标系、同一未来时刻的位置；
- [ ] 日志中的最小距离随 actor 接近而合理变化；
- [ ] 还没有向 `data.costs` 加任何动态风险。
