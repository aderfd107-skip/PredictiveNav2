# 16：对比原版 MPPI 基线

在相同地图、目标、动态 actor 路线和重复次数下，对比原版 MPPI 与加入 DynamicRiskCritic 后的结果。

对比关注成功率、碰撞/近碰、最小距离、耗时、路径长度和不必要停顿，而不是只挑一段最好看的视频。

完成标准：有一张诚实说明改善和代价的对照表，为第 05 模块实验记录准备输入。

## 本步手写范围

不新增 Critic 代码。你要亲自定义比较表、运行同一场景、汇总数据并写结论；这是把“功能能跑”升级为“项目可信”的最后一步。

## 固定不变的条件

```text
地图、机器人 footprint、起点、目标、actor 路线、actor 速度、最大速度、
prediction 参数、运行次数、成功/碰撞判定规则
```

唯一应变化的是 controller 配置：原版 MPPI 是否加入 `DynamicRiskCritic`。

## 结论必须同时写收益和代价

好的结论格式是：

> 在固定横穿场景下，动态风险版将最小距离从 A 提高到 B，但平均完成时间增加 C；在窄通道场景中仍会出现 D，因此需要在第 05 模块继续调参与重复验证。

不要写“加入预测后导航效果明显更好”，除非数据真的支持，并且同时报告失败样本和代价。
