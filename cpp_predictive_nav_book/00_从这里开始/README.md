# 从这里开始

你的目标不是成为“能默写所有 C++ 语法的人”，而是能理解、运行、修改、验证并逐渐参与编写 PredictiveNav2 的 C++ 代码。

现在项目已有机器人模型、Gazebo、RViz、`/scan`、TF、AMCL 与静态 Nav2 导航。下一块未实现的真实能力是：**只依赖自己的 LiDAR 数据，找出动态障碍物。**

因此不需要先完成参考区里的 C++ 小例子。主线从第一模块开始：先观察现有 `/scan`，然后创建一个真正订阅它的 C++ 节点。

当你学习时，只需要做到三件事：

1. 按文档复制运行命令；
2. 看见文档说明的结果；
3. 碰到不理解的行就停下问我，而不是跳过或硬背。

每个小步骤开始时，文档都会明确写出“这一小步需要你自己做什么”。在初期它通常只是运行一条命令或改一处已有配置，绝不会突然要求你从零写完整函数。
