# 00：这一模块要做什么

## 为什么第五章之后才做它

自定义局部规划器是项目的进阶优化，不是为了避开第 04 章的 MPPI 工作。

如果没有已经跑通的 `MPPI + DynamicRiskCritic`，也没有第 05 章固定好的场景、rosbag 与指标，就无法回答：

> 新规划器的效果更好，是因为它真的更合理，还是仅仅因为测试条件变了？

因此正确顺序是：先完成主线、先做真机验证、先保存基线证据；然后基于相同输入与同一套指标实现并优化第 06 模块。

## 这里的“自定义”具体指什么

不是自己写一个节点，看到障碍物后随手发布 `/cmd_vel`。那会绕开 Nav2 的目标管理、安全配置和恢复行为，也会和现有控制器抢同一个 topic。

首版采用更专业的方式：实现 `PredictiveLocalController`，作为 Nav2 的 `nav2_core::Controller` 插件。

```text
Nav2 仍负责：全局路径、导航 Action、BT、costmap、lifecycle、recovery

你负责：候选控制生成、机器人前向模拟、总 cost、最优局部速度
```

所以它是“**自己实现局部规划算法，复用成熟导航框架**”，不是“完全抛弃 Nav2”。

## 你的算法会如何工作

每个控制周期，规划器从当前机器人姿态和速度开始：

```text
采样 N 组控制 (v, ω)
        ↓
用差速运动学模拟每组控制未来 H 秒的机器人轨迹
        ↓
对每条候选求总代价 J
        ↓
选择 J 最小且安全的候选，输出第一个控制命令
```

总成本会逐步增加：

```text
J = J_path + J_goal + J_static + J_smooth + J_dynamic + J_ttc
```

- `J_path`：偏离全局路径越多，代价越高；
- `J_goal`：无法向目标方向推进，代价越高；
- `J_static`：接近 costmap 静态障碍或 footprint 碰撞，直接淘汰或高罚；
- `J_smooth`：速度变化太突然、旋转太猛，代价升高；
- `J_dynamic`：和预测障碍物在**同一未来时刻**接近，代价升高；
- `J_ttc`：即将发生碰撞的候选增加更高风险。

动态风险仍消费第三章的 prediction：

```text
机器人候选 r(t_k)  ↔  障碍物预测 o_i(t_k)
```

同一空间位置但不在同一时刻经过，风险不应被夸大；同一时刻会相遇，即使现在距离较远，也应提前扣分。

## 和 MPPI 的关系

| 方案 | 谁生成候选 | 谁计算动态风险 | 谁选择速度 |
|---|---|---|---|
| 原版 MPPI | Nav2 MPPI | 无自定义风险 | Nav2 MPPI |
| 第 04 模块 | Nav2 MPPI | 你的 `DynamicRiskCritic` | Nav2 MPPI |
| 第 06 模块 | 你的 Controller | 你的 Controller | 你的 Controller |

第 06 模块仍由 Nav2 Controller Server 调用，但算法核心不调用 MPPI。它的价值在于你能解释：候选怎样生成、差速模型怎样离散、每项代价为何存在、风险怎样进入最终决策，以及失败时如何安全降级。

## 真机时怎样接入

第 06 模块完成前，真机可以先跑第 04 章方案；二者需要的硬件接口相同：

```text
/scan、/odom、/tf、全局路径、/dynamic_obstacles/predictions
                                      ↓
                               局部 Controller
                                      ↓
                                   /cmd_vel
                                      ↓
                            底盘驱动 / 单片机速度闭环
```

新增的是软件实时性和安全要求，而不是另一套传感器：控制周期不能阻塞等待 prediction 或 TF；prediction 过期、全部候选碰撞、计算超时都要输出安全的降级行为；同时只能保留一个最终速度发布链路。

## 完成标准

完成第 06 模块时，应能做到：

- 在相同地图和同一 rosbag / actor 路线下复现实验；
- 解释每一项 cost 的物理含义与参数影响；
- 证明候选轨迹与动态障碍物按同一时刻对齐；
- 发生预测过期、碰撞或没有可行解时安全停车/交回恢复逻辑；
- 在仿真和真机中与原版 MPPI、MPPI + DynamicRiskCritic 做量化对比；
- 报告运行频率、单周期耗时、最小距离、到达率、路径长度和速度平滑性。
