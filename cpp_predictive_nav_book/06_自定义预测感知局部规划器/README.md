# 第六模块：自定义预测感知局部规划器（进阶）

> 开始条件：先完成第 04 模块的 MPPI 动态风险方案、第 05 模块的对照实验；真机验证可以先做，并不需要等第 06 模块。

## 这一模块要解决什么

第 04 模块中，Nav2 MPPI 负责生成候选机器人轨迹，我们只新增 `DynamicRiskCritic` 评分。第 06 模块进一步实现自己的局部规划核心：自己采样控制、前向模拟差速机器人、计算静态/路径/动态预测风险，并选择速度。

它不再调用 Nav2 MPPI，但首版仍实现为 `nav2_core::Controller` 插件：保留 Nav2 的全局路径、目标管理、生命周期、costmap 与恢复行为，避免为了证明局部规划能力而重复造整套导航基础设施。

```text
Nav2 global planner / BT / costmap
                  ↓ global path
PredictiveLocalController（你实现）
  ├── 采样候选 (v, ω)
  ├── 差速运动学前向模拟
  ├── 静态障碍、路径、目标、平滑性评分
  ├── prediction 时间对齐、TTC、协方差动态风险评分
  └── 选出最优局部控制
                  ↓
              Nav2 /cmd_vel
```

## 与前面模块的关系

| 模块 | 角色 | 第 06 模块如何使用它 |
|---|---|---|
| 01–03 | 从 LiDAR 得到带协方差的动态预测 | 作为动态风险输入，绝不使用 Gazebo 真值 |
| 04 | `MPPI + DynamicRiskCritic` 基线 | 证明自定义规划器不是“只在简单场景恰好能跑” |
| 05 | 固定场景、bag、指标、对照组 | 用同一套实验公平比较三种方案 |
| 06 | 自定义局部规划核心 | 只替换局部 controller，不推倒 Nav2 其他基础设施 |

最终至少比较：

```text
原版 MPPI
MPPI + DynamicRiskCritic
PredictiveLocalController（自定义局部规划器）
```

## 本模块完成后的项目定位

完成后，项目可以诚实定位为：

> 面向动态障碍物的预测感知移动机器人局部规划系统：基于 2D LiDAR 完成多目标跟踪和不确定性预测，并实现 MPPI 风险 Critic 与自定义采样式局部规划器，在同一仿真/真机场景下进行对照评估。

这比“激光导航调参项目”更偏向局部规划、轨迹优化和规控工程。

## 边界

- 第 06 模块不是当前真机验证的前置条件；先把第 04/05 模块与真机链路稳定下来。
- 首版不从零重写全局规划、行为树、AMCL 或 costmap。
- 若未来要做完全脱离 Nav2 的控制节点，应作为第 06 模块完成后的独立扩展；它会额外带来命令仲裁、目标管理和恢复逻辑，不能与 Nav2 同时向 `/cmd_vel` 发布。
