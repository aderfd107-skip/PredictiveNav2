# 第五模块：把“能运行”变成可信、可展示的项目

## 这块要解决什么

代码跑出一次好结果，不等于项目已经被验证。本模块把测试条件固定下来，记录数据、做重复对比，并把真实的优点、限制和复现方法整理成别人能检查的材料。

**项目表达**不是包装虚假的成果，而是让老师、面试官或合作人能快速理解：你解决了什么问题、怎样验证、结果如何、哪里还有限制。

## 最终会得到什么

```text
可重复启动的场景 + rosbag 输入录像 + CSV 指标
        ↓
基线/动态风险方案的重复对比 + 图表
        ↓
技术 README + 演示视频 + 简历项目描述 + 面试讲解提纲
```

## 三条原则

- 只写实际完成、能复现的结论；仿真真值可用于离线评估，但不能混入算法输入。
- 同一个比较必须使用同一地图、目标、障碍物路线和指标定义。
- 失败案例也要保存；它们比“只截一张成功图”更能说明你理解系统。
