# 00：这一模块要做什么

第 01 模块每帧发布“这里有一团激光点”的 cluster。第 02 模块要跨很多帧观察它们，为同一个物体保持同一个 ID。

可以把差别理解成：

```text
cluster：这一张照片里看到了什么
track：  连续视频里，哪个物体一直是同一个
```

最终一条 track 会包含位置、速度、尺寸、协方差、年龄和丢失计数。它既可能对应移动方块，也可能对应静态墙面；“是否动态”不能只凭第一帧决定。

本模块的循环顺序固定为：

```text
收到一帧 clusters
→ 计算 dt
→ 预测所有旧轨迹
→ 将新观测和旧轨迹匹配
→ 用匹配观测更新轨迹
→ 为未匹配观测新建轨迹
→ 为未匹配旧轨迹增加 missed 计数
→ 发布 tracks
```
