# 10. 项目交付与面试表达

## 本阶段交付

完成 README、架构图、运行说明、实验结果、演示视频和面试问答材料。

## 本章新学知识

- 以问题—设计—实现—验证—局限性讲解项目。
- 用数据描述结果，不把 Gazebo 真值误写为算法能力。
- 解释 TF、QoS、Kalman Filter、协方差、MPPI Critic 和性能设计。
- GitHub 项目呈现与简历项目描述。

## 完成标准

陌生开发者能从 README 构建并运行；你能在 5 分钟内清楚讲解项目，也能深入回答一个模块的设计选择。

## 面试复盘题库

开发中出现过的真实问题、回答边界和可拿出的证据，统一整理在 [../interview_question_bank.md](../interview_question_bank.md)。面试前先核对其中的“当前状态”，不要把计划写成已完成能力。
