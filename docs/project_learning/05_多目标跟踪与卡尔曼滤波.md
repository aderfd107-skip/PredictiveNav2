# 5. 多目标跟踪与卡尔曼滤波

## 本阶段交付

实现 `predictive_nav_tracking`：将 clusters 转换为带稳定 ID、位置、速度、协方差和生命周期的 `/dynamic_obstacles/tracks`。

## 本章新学知识

- Eigen 固定尺寸向量/矩阵：`Vector4d`、`Matrix4d`。
- 恒速模型：`x=[px, py, vx, vy]^T`，以及 `F/H/Q/R/P`。
- Kalman predict/update、Joseph covariance form、`dt` 验证。
- 最近邻关联、gating、未匹配观测、新建/丢失/删除 track。
- `std::unordered_map`、`std::optional` 与可测试类设计。

## 实施顺序

1. 先写不依赖 ROS 的 `KalmanTrack`，用 gtest 验证。
2. 实现关联与生命周期管理。
3. 最后接 clusters 和 tracks 消息。

## 完成标准

actor 连续运动时 ID 稳定；短时漏检不会随意换 ID；速度、协方差和非法 `dt` 行为可解释。
