# 7. 原版 MPPI 导航基线

## 本阶段交付

不接入预测结果，先让 Nav2 原版 MPPI 在同一地图、起终点和场景下稳定运行，并记录与 DWB 的对照数据。

## 为什么不能跳过

如果没有原版 MPPI baseline，就无法证明自定义 Critic 带来的改善，也无法区分插件问题和控制器配置问题。

## 本章新学知识

- DWB 与 MPPI 的职责和采样评分差异。
- Nav2 lifecycle、controller 配置、costmap 和速度链路。
- 使用日志、动作结果和 RViz 排查导航失败。
- 对照实验中的场景、参数与起终点固定。

## 完成标准

原版 MPPI 能完成至少一组重复导航；其配置、结果和已知限制被记录。
