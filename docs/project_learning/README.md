# PredictiveNav2：按项目步骤学习与实现

本目录不是按“C++ 课程章节”排列，而是按项目真正的开发顺序排列。每一章都是一个可交付的项目里程碑；其中的 **本章新学知识** 列出为了完成这一步才需要学习的 C++、ROS 2、数学或工程知识。

学习原则：只阅读当前章节，先自己写，再构建、运行和验证。卡住时带着章节名、代码、完整报错和自己的思路提问。

## 最终数据流

```text
/scan → 动态障碍物检测/聚类 → 多目标跟踪 → 轨迹预测
      → DynamicRiskCritic → Nav2 MPPI → benchmark
```
